# linux-networking-lab

Hands-on Linux server and networking lab built on an Ubuntu VM.

## Progress

- [x] Ubuntu VM provisioned
- [x] Nginx hosting a static site
- [x] Users restricted to SSH key authentication (password login disabled)
- [x] UFW firewall configured
- [ ] Bash script reporting CPU, disk, memory, with email alerts above 80% disk
- [ ] Script running as a systemd service with cron scheduling
- [ ] 30+ commands documented with usage context
- [ ] Network diagram (DNS, TCP, TLS, HTTP)
